# Egresos Hospitalarios

Sistema de esgresos hospitalarios. Recopila información de todas las áreas que emiten censos. Conecta y replica las tablas de aletheia y hace segimiento del paciente desde sus ingreso

## Situación actual

Actualmente hay 4 personas involucradas solo en el proceso de redactar los egresos hospitalarios. Hay datos en los censos que las áreas no redactan, por lo que hay un cuello de botella de redacción y completado de datos. Ese completado se realiza para facilitar el trabajo de actualizar los egresos digitalmente a Alethia.

## Objetivo

Optimizar el procesos en un sistema web óptimo.
